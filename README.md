# AORI-ANIME
Синий дизайн каталога аниме. Аватар сервера сохранён в формате GIF как `aori-avatar.gif` и используется в шапке, hero-блоке, каталоге и футере.

Для GitHub Pages загрузите все файлы из этой папки в корень репозитория.
