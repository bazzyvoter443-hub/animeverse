# AORI-ANIME — русская версия с прямым плеером

Эта версия сохраняет дизайн из `AORI-ANIME-FIXED.zip` и исправляет страницу просмотра:

- интерфейс переведён на русский;
- на странице аниме используется встроенный HTML5-плеер;
- можно добавить серии и несколько дорожек/озвучек через `streams.js`;
- GIF `aori-avatar.gif` остаётся в проекте и продолжает работать.

## Важно

AniList API используется только для метаданных и не предоставляет сами видеофайлы.
Для прямого просмотра необходимо добавить в `streams.js` собственные или лицензированные
видеофайлы/потоки, на которые у владельца сайта есть право показа.

## Загрузка на GitHub Pages

Загрузите все файлы из архива в корень репозитория, включая:

- `index.html`
- `anime.html`
- `app.js`
- `styles.css`
- `streams.js`
- `aori-avatar.gif`
- `.nojekyll`
- `404.html`

После обновления GitHub Pages сайт будет работать как раньше, а страница просмотра


## Просмотр на странице

Каталог автоматически передаёт AniList ID выбранного аниме в `anime.html?id=...`.
Встроенный HTML5-плеер использует записи из `streams.js`. AniList даёт метаданные и ID, но не видеосерии, поэтому для воспроизведения нужно добавить разрешённые/лицензированные URL видео в `streams.js`.
