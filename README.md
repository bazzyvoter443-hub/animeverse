# AnimeVerse Player Demo

Статический проект для GitHub Pages / Cloudflare Pages.

## Возможности
- каталог AniList;
- поиск и жанры;
- страница аниме;
- интерфейс серий;
- HTML5-плеер;
- загрузка собственного видеофайла;
- загрузка разрешённого прямого URL;
- заготовка выбора аудиодорожек и субтитров;
- сохранение позиции просмотра в localStorage.

## Публикация на GitHub Pages
Загрузите ВСЕ файлы из этой папки в корень репозитория:
index.html, anime.html, app.js, styles.css, 404.html, .nojekyll, README.md

Затем Settings → Pages → Deploy from a branch → main → /(root) → Save.

Важно: AniList API используется для метаданных. Для видео используйте только собственные или лицензированные источники.
