# AORI-ANIME

Статический каталог аниме для GitHub Pages / Cloudflare Pages.

## Что изменено

- Убраны трейлеры и YouTube.
- Страница аниме автоматически получает по AniList ID метаданные и доступные `streamingEpisodes`.
- AniList описывает `streamingEpisodes` как ссылки на легальные эпизоды на внешних сайтах.
- Дополнительно показываются доступные внешние ссылки из `externalLinks`.
- Если владелец сайта добавит собственный разрешённый источник в `streams.js`, видео воспроизводится прямо на AORI-ANIME.

## Важно

AniList ID — это ID записи каталога, а не видеофайла. AniList не раздаёт сами серии. Поэтому прямой просмотр на AORI-ANIME работает только для видеоисточников, которые владелец сайта имеет право показывать и добавил в `streams.js`.
